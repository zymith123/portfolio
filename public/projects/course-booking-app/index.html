Course Booking App

A class and course booking application where visitors can register, browse available courses, and enrol, and where administrators manage the catalogue.

Personal project React · Node.js · Express · MongoDB

Overview

A full-stack MERN application built around a course catalogue. It covers the full loop: an account system, a public listing of courses, a detail view per course, enrolment, a user profile, and an admin side for adding courses and activating or archiving them.

Key functionality

  • Registration, log in and log out.
  • User profile.
  • Browse all courses and view a single course.
  • Enrol in a course.
  • Admin: add a course, activate or archive a course.
  • Role separation between a regular user and an admin user.

Technology

ReactNode.js ExpressMongoDB

Notes

This was an earlier full-stack build and is included as supporting work rather than a headline project. The admin area is protected; a walkthrough is available on request.
