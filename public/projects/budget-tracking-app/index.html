Budget Tracking App

KWENTA — a personal budget tracker for recording income and expenses and keeping an eye on your balance over time.

Personal project Next.js · Node.js · Express · MongoDB

The problem

Keeping a running picture of personal cash flow — what came in, what went out, and what’s left — usually lives in a notes app or a spreadsheet that’s easy to abandon. The aim here was a small, focused web app: log a transaction in a few seconds and always see the current balance.

What I built

  • User accounts with sign-up and log in.
  • Recording of income and expense transactions.
  • A running balance derived from the transaction history.
  • A REST API over MongoDB for persisting users and transactions.

The exact feature set (categories, charts, editing) is being confirmed and this list will be tightened to match what’s in the app.

Technology

Next.jsReact Node.jsExpress MongoDB

Key technical decisions

  • Balance is derived, not stored. The current balance is computed from the transaction history rather than kept as a separate field, so it can never drift out of sync with the entries.
  • Separate API and client. An Express/MongoDB API handles persistence; the Next.js app handles the interface and talks to it over REST.
  • Authentication gates the data. Transactions belong to a user account, so each person only sees their own records.
